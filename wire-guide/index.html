Wire: build a 3D renderer in plain JavaScript

Fourteen chapters. Each one ends with something that works on screen, and each one makes you use a part of JavaScript you may feel unsure about. You write the code. This page gives goals, theory, and hints that start vague and get more specific.

The figure on the right is your target: points and matrices in, a 2D canvas drawing that reads as 3D out. Try not to read its source until you've finished chapter 7.

How to use this guide

Read, then buildEach chapter links the javascript.info pages it relies on. Skim them first, then go back to the parts you need while you work.
Hints come in tiersTier 1 points you in a direction, tier 2 names the tool, tier 3 is close to pseudo-code. Wait 15 minutes of being stuck before opening the next one.
Answer the self-checkAnswer each question out loud before you open it. If you can't explain something, that's the javascript.info page to reread.
Tasks are specsEach task says where the code goes, what it takes and returns, and a done when check you can run. How to write it is up to you; that's what the hints are for.
Commit per chapterUse git and commit at the end of every chapter so you can compare later code with earlier code. Your progress on this page is saved in this browser only.

The road map

    Theory links point to javascript.info. Dashed links go to MDN, for topics javascript.info doesn't cover (Canvas, requestAnimationFrame, Web Workers). The geometry formulas are standard math, given here so you spend your time on the JavaScript. Each "The maths, in plain words" section explains the ideas behind them and links to Wikipedia, Maths is Fun, 3Blue1Brown, BetterExplained, Scratchapixel, LearnOpenGL and similar pages for a deeper explanation.
